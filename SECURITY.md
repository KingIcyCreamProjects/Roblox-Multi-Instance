# Security

RMI stores Roblox session cookies, so security bugs matter here.

Please do not open a public issue for a vulnerability. Report it privately through GitHub: the Security tab of this repository, then "Report a vulnerability". Include what you found, how to reproduce it and the RMI version.

Never paste a real `.ROBLOSECURITY` cookie, a vault file, a friend remote password or a pairing code into an issue, a pull request or a log you attach.

How the vault, friend remote and remote access are protected is described under "Security model" in the [README](README.md).
